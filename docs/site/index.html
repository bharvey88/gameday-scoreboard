Game Day Scoreboard

Football scoreboard for the Apollo M-1 HUB75 matrix. Version __VERSION__.

What it looks like during a game. This is the panel's built-in demo mode: a scripted game with the real celebrations.

1. Install

Plug the M-1 into this computer over USB and click Install. One firmware covers a single 64x64 panel and two panels side by side; you pick which on the device page afterwards.

This browser cannot talk to the M-1 over USB. Try a desktop browser. Open this page over HTTPS to install.

Installing erases whatever firmware was on the M-1. Your WiFi details and team choice are asked for afterwards.

2. Join WiFi

When the install finishes the same dialog offers to connect the device to WiFi. Enter your network name and password. If you skip it, the panel starts a hotspot called Game Day Scoreboard; join it and a setup page opens.

3. Pick your team

The panel itself tells you where to go once it's online: open the gameday-xxxxxx.local name it shows on your phone, or the address shown under it if your phone doesn't resolve .local names.

  1. Tap Change team and pick from the logos, or use the On now tab to jump into a game that's already playing. NFL and every FBS college team are there.
  2. Two panels side by side? In the Setup card, click the two-panel picture. The matrix restarts using both.
  3. The timezone follows the phone or computer you opened the page on, so kickoff times read right without setting anything.
  4. Optional: the ticker parts, opponent celebrations, favorite teams for a WizMote remote, or a live mode that follows a random game in progress.

The panel shows the next game with the line, TV network and kickoff, switches to the live layout at kickoff, celebrates scores, and lingers on the final. The page mirrors it, lists the next three games, and updates the firmware when a new version is out. Everything is fetched from ESPN by the device itself. No Home Assistant needed, though the device does show up there if you want it.

Source, issues and the YAML for building it yourself: bharvey88/gameday-scoreboard. Built on hub75-studio and ESPHome.
